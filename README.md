# app_for_notebooks

Утилита пост-обработки результатов извлечения лотов из PDF в табличный формат.

## Что делает

Скрипт `postprocess_lots.py`:
- удаляет фейковые/служебные строки (заголовки таблиц, шум);
- удаляет все колонки с фото (`Photo1..Photo13`);
- восстанавливает часть полей из `RawText` (позиция, город, тип, бренд, модель, серийный номер, диагональ, цена);
- объединяет дубли одной позиции, оставляя наиболее полную строку;
- переводит заголовки колонок на русский язык;
- добавляет полезные аналитические колонки:
  - `Идентификатор_лота`;
  - `Наличие_серийного`;
  - `Цена_числом_руб`;
  - `Полнота_заполнения_проц`;
  - `Проблемные_поля`.

## Запуск

```bash
python postprocess_lots.py input.xlsx output.xlsx --stats-json stats.json
```

Поддерживаются вход/выход как `CSV`, так и `XLSX`.
